# qt
学生版是最新的函数绘图工具版本，主要的文件包括mainwindow.cpp mainwindow.h  stucontrol.cpp  stucontrol.h，其余的文件保持默认，导出功能也是在这几个文件当中实现的，也就是说export文件并没有使用到。
程序依赖人工智能工具修改代码实现了所有的功能，部分的代码添加了注释，可能注释不是非常好理解和准确，请自行分辨。程序可以绘制常见的数学函数图像，例如sin tan cos 等三角函数，tan函数比较特殊，不好修改，存在一些小小的问题，但是没有影响。其余的函数log函数和arccos函数以及y=n的常函数，实现部分主要关于mainwindow中的hanshujisuan这个函数，另外程序有图像的颜色选择，线宽选择，网格的大小修改，实线和虚线的修改，坐标轴边界的变化，坐标轴的显示和不显示的复选框等，图像绘制的提示，最后还有导出图像的功能等，具体内容可以查看头文件的注释。
